# Glitch Shader Effects

This directory contains custom glitch shader effects designed specifically for the DBZ/Anime aesthetic.

## Custom DBZ Anime Glitch Shader

**Files:**
- `DBZ_AnimeGlitch.shader` - The main shader file
- `DBZ_AnimeGlitch.mat` - Default material using the shader

**Features:**
- **Anime-Style Visual Effects**: RGB channel separation, scan lines, and digital interference
- **Energy Pulse Effects**: Pulsing distortions that simulate ki/energy interference
- **Customizable Parameters**:
  - Glitch Intensity: Overall strength of the effect
  - Scan Line Speed: How fast scan lines move
  - RGB Shift: Color channel separation amount
  - Noise Amount: Digital interference level
  - Pixelation: Retro pixel effect
  - Distortion: Screen warping
  - Energy Pulse: Ki energy fluctuation timing
  - Time Scale: Speed of all time-based effects

**Usage:**
1. Apply the `DBZ_AnimeGlitch.mat` material to a UI Image or Quad
2. Adjust parameters in the Inspector for desired effect
3. Use during power-ups, transformations, or dramatic moments
